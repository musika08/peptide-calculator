# 🧪 PeptideCalc Pro v1.0

**PeptideCalc Pro** is a specialized dashboard designed to simplify the complex math involved in peptide reconstitution. It serves as both a precision calculator and an educational knowledge base for researchers.

### 🔗 [Click Here to Launch the App](https://YOUR-APP-URL-HERE.streamlit.app)
*(Replace the link above once you deploy on Streamlit Cloud)*

---

## 🚀 Features

* **🛡️ Safety-First Design:** Prominent warnings and safety checks to ensure stock dosages and water volumes match physical supplies.
* **📚 Knowledge Base:** Built-in profiles for popular peptides (BPC-157, Semaglutide, Tirzepatide, etc.) including:
    * *Mechanisms of Action*
    * *Common Dosing Frequencies*
    * *Timing Protocols (e.g., Fasted vs. Fed)*
    * *Injection Site Diagrams*
* **⚡ One-Page Dashboard:** A clean, wide-layout interface that displays inputs and results side-by-side without scrolling.
* **💾 Downloadable Protocols:** Generate and save a text file with complete mixing and dosing instructions for your records.
* **💉 Syringe Support:** Toggle between U-100 (Standard) and U-40 (Veterinary) insulin syringes to prevent dosing errors.

## 🛠️ How to Run Locally

If you prefer to run this on your own computer instead of the web:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/peptide-calculator.git](https://github.com/your-username/peptide-calculator.git)
    cd peptide-calculator
    ```

2.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the app:**
    ```bash
    streamlit run app.py
    ```
